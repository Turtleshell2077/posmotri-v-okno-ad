# Посмотри в окно

Проектная работа Яндекс Практикума — приложение, которое показывает видео из окон разных городов. Можно искать по городу и времени суток.

Сделано на HTML и CSS: флексы, кастомные чекбоксы через псевдоэлементы, состояния :hover, :active и :focus-visible, БЭМ. Логика на JavaScript была в заготовке.

Ссылка на репозиторий: https://github.com/Turtleshell2077/posmotri-v-okno-ad
